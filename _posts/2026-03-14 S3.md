## Simple Storage Service S3

- we can modify the storage class of each object in a bucket
- Using the console we cannot delete a bucket which has objects
  - using the CLI we can remove objects recursively using `aws s3 rm s3://amzn-s3-demo-bucket --recursive`
- we can use s3api which is a sub-command of the AWS CLI specifically for S3, but at a lower level than aws s3 for fine grained control
